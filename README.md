# Mani AI

Urdu / Roman Urdu voice assistant.

- **Android app** (`app/`): voice commands, phone control via Accessibility Service, Claude API for natural language.
- **Web version** (`docs/index.html`): browser voice assistant on GitHub Pages. Limited: opens sites and chats, cannot control the phone.

## Build APK
Push to `main`, open the Actions tab, download the `ManiAI-debug-apk` artifact.

## API key
Never commit your key. Enter it inside the app or website; it stays on your device/browser only.
